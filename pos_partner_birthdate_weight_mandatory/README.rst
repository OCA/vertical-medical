This module requires the customer's weight to be entered in the Point of
Sale interface if the "Age Warning" setting applies to the selected
customer.

**Table of contents**

.. contents::
   :local:

Configuration
=============

1. Go to POS settings
2. Go to the POS Interface section
3. Check the Weight Required setting

Usage
=====

This module only functions when the "Age Warning" setting is configured.

A popup will notify the cashier that the customer's weight is required
based on their date of birth, as specified by the Age Warning setting.
The cashier must then enter the customer's weight in the customer
details form.
