POS Order Line Customer History Split Invoice Info
==================================================

This module extends the functionality of the following modules:

- pos_order_line_customer_history
- pos_order_split_invoice

Purpose
-------

The main goal of this module is to enhance the customer history view for
POS order lines by indicating the payment status of associated split
invoices.

Features
--------

- Displays a warning icon on order lines in the customer history view if
  the corresponding split invoice is not fully paid.
- Helps POS users quickly identify payment issues at the line-item
  level.
- Improves visibility and follow-up for partial or unpaid invoices
  created from split payments.
